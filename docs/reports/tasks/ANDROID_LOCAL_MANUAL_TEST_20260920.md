## 1. 测试目标

在现有 `Foursquare_API_34_x86_64` 专用模拟器上，以用户可见入口验证当前 Debug development 构建的首次启动、主要页面导航、本地对局、PVE、基础设置与生命周期稳定性。初始测试只记录问题；用户后续明确要求修复确认问题后，`BUG-AND-001` 至 `BUG-AND-003` 已修正并完成自动化与模拟器复测。

- 构建：`flutter run --no-pub --dart-define=ENV=development`
- 包名：`com.qoder.foursquare`
- 屏幕：1080 × 2400，初始为竖屏
- 证据目录：`build/manual-test-20260920/`
- 数据策略：保留当前应用数据，不执行 wipe；从当前首次启动引导页继续

## 3. 本轮范围边界

- 执行：单设备可见 Phase 1 页面、PVP/PVE 基础走棋、设置、后台恢复、崩溃/ANR 检查。
- 暂不执行：LAN 双设备联调、隐藏在线入口、隐藏语音/冥想入口、真实扬声器听感、真机权限、正式签名与商店流程。
- 处理原则：先记录严重级别、复现步骤和证据；确认修复范围后以失败回归测试驱动修正，保留原始与修复后证据。
