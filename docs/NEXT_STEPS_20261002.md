- 续局体验：从已保存历史恢复上一手起终点及完整吃子标记；空历史无标记，失败终局补记保留最后一步。存档版本及棋局状态保持原样。
- 困难 AI：先减少根搜索冗余，再增加基础前瞻 6→8；简单/中等仍为 2/4，三档时间上限仍为 100/500/1800 ms，超时仍采用最后完整迭代。
- 按失败回归、真实 Hive、真实页面、战术 oracle、缓存契约和独立种子基准验证；设备验收绑定本轮 APK。
- 本轮具体结果见 [优化报告](reports/tasks/RESUME_AI_REFINEMENT_20261002.md)。

## 3. 需要设备或环境后推进

1. Android：补充系统版本矩阵；真机 Profile/Release 的困难 AI、持续走棋、动画、内存趋势和长期运行；真实低内存/低存储及进程重启。
2. LAN：双 Android 设备同一 Wi-Fi/热点，覆盖发现、加入、双吃同步、30 秒重连、超时与复局。
3. Online：隔离 staging 的真实 PostgreSQL migration/回滚、outbox 双 worker/慢租约、TLS、服务重启恢复、负载、备份恢复和数据删除。本地双客户端真实 Node 传输已验证，环境门禁继续保留。
4. iOS 与语音：Mac/iPhone/iPad 的平台、权限、音频中断、中文识别/TTS 完成时序及无屏整局验收。

设备与外部环境未齐备时继续执行 A1–A4，不安装大型镜像或服务组件。
